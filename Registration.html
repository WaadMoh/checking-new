Step 1

Open and Sign In to ECAE Portal

  1. Open the ECAE Portal.
  2. Sign in using your ECAE username and password.
  3. Select the Students tab.
If you cannot access the portal, reset your password through Office 365 and try again. Important:
Students using other corporate devices may need to sign in using the following username format:

ECAE\StudentID
Example: ECAE\001164
Step 2

Open Registration Letter Request

  1. Open Student Service.
  2. Locate Registration Letter Request.
  3. Select the Registration Letter Request tile.
Registration Letter Request is available from Student Service.
Step 3

Submit Registration Letter Request

  1. Select Add New Registration Letter Request.
  2. Complete the required information.
  3. Review the request details.
  4. Submit the request.
  5. Wait for processing.
Registration letters can be requested for banks, scholarships, visa applications, employers, and other official purposes.
